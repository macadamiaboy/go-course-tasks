Prometheus
В качестве метрик были взяты httpRequestsTotal и httpRequestDuration из конспекта
Также к ним была добавлена метрика httpRequestsInFlight, позволяющая считать число выполняемых в данный момент запросов
Таким образом, полностью реализуется методология RED, учитывающая частоту запросов, ошибки и их длительность

Получить метрики можно по ендпоинту /metrics
